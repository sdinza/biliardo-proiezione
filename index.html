Alignement sur le tapis

Placez les quatre coins du cadre sur les coins intérieurs du tapis. Après l’enregistrement, gardez la tablette, son orientation et le projecteur dans la même position. Le menu n’est pas concerné par cet alignement.

Installer Billard

Sur Samsung / Android : ouvrez cette page dans Chrome, touchez ⋮, puis Installer l’application ou Ajouter à l’écran d’accueil.

Ensuite, lancez Billard depuis son icône. Dans Réglages, attendez le message « Prêt hors connexion » avant de déconnecter le Wi-Fi.

Pour ajouter des exercices : Réglages → Importer des exercices, puis choisissez le fichier HTML ou JSON du créateur. Aucun compte GitHub n’est nécessaire sur la tablette.
