# Billard Club

Application de projection pour tablette Android, en français.

Ouvrez https://sdinza.github.io/biliardo-proiezione/ dans Chrome, puis choisissez Installer l’application. Dans Réglages, attendez « Prêt hors connexion ».

Pour ajouter des exercices : envoyez depuis le PC le fichier HTML ou JSON exporté par le créateur. Sur la tablette, ouvrez Billard → Importer des exercices. Vous pouvez aussi utiliser Partager → Billard si Android le propose. Les exercices restent sur cet appareil ; aucune publication GitHub n’est nécessaire.

Le cache hors connexion peut être supprimé par le système ou en effaçant les données de l’application : conservez les fichiers d’origine.
